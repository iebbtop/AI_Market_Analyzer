如何自定义模板

{任务}
分析品种	将“黄金”改为其他品种	“预测EURUSD 15分钟后走势”

{评分系统}
评分指标	增减指标或调整权重	如：加入“成交量”或“ADX”
开仓条件	改变分数阈值,信号强度≥4分 属于 评分系统控制,也就是 MA/MACD/RSI/布林带的打分达到阈值后，才应该输出做多/做空。

### 评分系统（满分±5分）
1. **MA均线**：多头排列/空头排列/震荡
2. **MACD**：多头趋势/空头趋势/震荡
3. **RSI**：超买/超卖/中性
4. **布林带**：突破上轨/突破下轨/中轨震荡
5. **成交量** 多头趋势/空头趋势/震荡
   
{分析要点的作用}
“波动性、支撑阻力、K线形态”是 辅助判断依据，用来提高建议质量，不是你这条阈值的直接计分项（除非你在提示词里把它们也纳入打分）。

{交易建议要求}
输出格式	控制AI回答结构	强制输出“方向-止损-止盈-风险比”
语言风格	可要求英文、繁体等	“请用英文简洁回答”


所以当前真实控制链是：
评分系统（在AI脑内） -> AI给出“做多/做空/观望” -> EA按关键词执行。
